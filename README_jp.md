# EnemyModify 1.6.1

- READMEと更新履歴はGitHubリポジトリで確認できます。ReleaseのZIPには含まれません。


[한국어](README_ko.md) · [English](README_en.md) · [日本語](README_jp.md) · [中文](README_zh.md)

セフィリアのモンスター禁止・ランダマイザー・エリートモンスターを設定するモッドです。ゲーム内の［EM 設定］から変更できます。QoLやDungreedEnemiesがなくても使えます。

## 1.6.1 — 2026-09-15

- 配布版の更新履歴は `patchlog` ファイルで確認できます。

## 主な機能

- モンスター禁止：階層ごとに通常モンスター・中ボス・ボス候補を選びます。進行に必要な最後の候補は残します。
- ランダマイザー：通常モンスターと中ボスを入れ替え、階層別に設定できます。
- モディファイア：23種類の許可・確率・ティアの重み・報酬を設定できます。
- 設定・名前・説明・通知はゲーム言語に合わせて韓国語・英語・日本語・中国語で表示されます。
- `/em ban all`で一括禁止、`/em ban off`ですべて解除できます。
- マルチプレイでモディファイアを使う部屋は全員にEMが必要です。ラン設定はホストが決めます。

## インストール

ZIPを`Sephiria/AddOns/EnemyModify`に展開してください。`metadata.json`・DLL・`Libs`を同じフォルダーに保管してください。

## 自動アップデート

ゲームに入ると新しいバージョンを確認し、ロビーで［今すぐアップデート・後で通知・このアップデートをスキップ］を選べます。今すぐアップデートを押すとダウンロードしてゲームを再起動します。ラン中は自動でウィンドウを開いたり終了したりしません。

`/em update`で手動確認できます。EM 設定の［一般］タブで［自動アップデート］をオフにすると、起動時の確認と更新ウィンドウが止まり、`/em update`でのみ確認できます。`/em update off`と`/em update on`も同じ設定を切り替えます。スキップしたバージョンも手動確認で表示できます。

ファイルは検証後に適用し、設定は引き継ぎます。Libsが変更されたバージョンはZIPをダウンロードし、ゲームを終了してから上書きしてください。

この機能がない旧版では、最初の1回は新しいZIPを手動でインストールしてください。

[更新履歴](patchlog_jp.md)

ゲームに入り、キャラクターとチャット表示の準備ができると、`[EnemyModify] 最新バージョンです。` または新版の通知が一度表示されます。更新ウィンドウは他のモッドのウィンドウが閉じてから開きます。自動確認をオフにした場合やスキップした版では自動の更新ウィンドウは出ません。
