## 최근 변경 — 1.6.7 (2026-09-17)

- README와 업데이트 기록을 현재 기능에 맞게 정리했습니다. 보스·중간 보스 기절·빙결 무시 옵션, 자동 업데이트 설정과 수동 설치 방법을 보완했습니다.
- 이번 버전에는 게임 동작 변경이 없습니다.

## 주요 기능

- 몬스터 밴: 층별 일반 몬스터 · 중간 보스 · 보스 후보를 고릅니다. 진행에 필요한 마지막 후보는 남겨 둡니다.
- 랜더마이저: 일반 몬스터와 중간 보스를 바꾸며 층별 설정을 지원합니다.
- 모디파이어: 23종의 허용 여부 · 확률 · 티어 가중치 · 보상을 설정합니다.
- 설정 · 모디파이어 이름과 설명 · 알림은 게임 언어에 따라 한국어 · 영어 · 일본어 · 중국어로 표시됩니다.
- `/em ban all`로 일괄 밴하고 `/em ban off`로 모두 풉니다.
- 멀티플레이의 모디파이어 방은 참가자 모두 EM이 필요합니다. 런 설정은 호스트가 정합니다.
- 보스·중간 보스 기절·빙결 무시: [일반] 탭에서 켤 수 있습니다(기본 꺼짐). 얼음 피해와 동상 중첩은 유지되며, 멀티플레이에서는 호스트 설정을 따릅니다.

## 설치

게임을 종료한 뒤 최신 Release의 `EnemyModify.zip`을 받아 `Sephiria/AddOns/EnemyModify`에 압축을 풀어 주세요. ZIP 안의 `metadata.json`, `EnemyModify.dll`, `Libs`가 이 폴더 바로 아래에 있어야 합니다. 기존 설치를 갱신할 때는 같은 위치에 덮어쓰고 `EnemyModify.json`과 `update-settings.json`은 유지하세요.

## 자동 업데이트

게임에 들어가면 새 판을 확인하고, 로비에서 [지금 업데이트 · 나중에 다시 알림 · 이 업데이트 건너 뛰기]를 묻습니다. 지금 업데이트를 누르면 받아서 게임을 다시 켭니다. 런 도중에는 자동으로 창을 띄우거나 게임을 끄지 않습니다.

`/em update`로 직접 확인할 수 있습니다. EM 옵션의 [일반] 탭에서 [자동 업데이트] 체크를 끄면 게임을 켤 때 새 판을 확인하거나 업데이트 창을 띄우지 않고, `/em update`로만 확인합니다. `/em update off`와 `/em update on`도 같은 설정을 끄고 켭니다. 건너뛴 판도 직접 확인하면 다시 볼 수 있습니다.

[일반] 탭에서 자동 업데이트 체크를 다시 켜면 다음 게임 실행부터 자동 확인이 적용됩니다. 바로 확인하려면 `/em update`를 입력하세요.

받은 파일은 검증한 뒤 적용합니다. 설정은 그대로 남습니다. Libs가 바뀐 판은 안내에 따라 ZIP을 받아 게임을 끈 뒤 덮어써 주세요.

이 기능이 없는 구버전에서는 처음 한 번 새 ZIP을 직접 설치해야 합니다.

[업데이트 기록](patchlog_ko.md)

게임에 들어와 캐릭터와 채팅창이 준비되면 `[EnemyModify] 최신 버전입니다.` 또는 새 업데이트 알림이 한 번 표시됩니다. 새 판의 업데이트 창은 다른 모드의 창이 닫힌 뒤 차례로 열립니다. 자동 확인을 껐거나 해당 판을 건너뛴 경우에는 자동 업데이트 창이 나타나지 않습니다.
